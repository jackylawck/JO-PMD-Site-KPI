📌 專案摘要 (Executive Summary)

東淦 PMD 地盤同事 KPI 考核系統 (jo-pmd-site-kpi) 是東淦工程有限公司專為地盤項目管理部（PMD）及工程現場主管自主設計的數位化績效評核平台。

本系統將企業傳統紙本《高級管工關鍵績效指標 (KPI) 考核協議書》全面系統化，以 Streamlit 自適應 Web 引擎與純 Python ReportLab 報表核心 為基座。系統落實無資料庫零資料留存 (Zero-Data-Retention) 架構，在兼顧極致隱私保護與香港《個人資料（私隱）條例》(PDPO) 的前提下，實現「地盤數據實時動態算分 ➔ ISO 7.5 單據追溯 ➔ 一票否決合規審核 ➔ 四方審核簽署 A4 報告匯出」的無紙化治理閉環。

🏛️ 流程生命週期與治理閉環 (Governance Lifecycle)

針對傳統地盤考核「紙本難攜、人工手算易錯、扣分口說無憑、審計鏈斷裂」的痛點，本系統建立完整的四階數位化治理流程：

階段一・現場量測
行動端即時動態算分
主管單手操作輸入原始次數與成本，系統以毫秒級即時運算 11 項 KPI 得分與百分比。
階段二・憑證追溯
ISO 7.5 證據鏈綁定
每筆評分強制或選填對應之地盤日誌、驗收批次單號或安全巡查檔號，確保可核實性。
階段三・合規審核
一票否決與 PIP 連動
客觀檢核嚴重失聯或人為重大事故，自動判定 F 級並直接連動 ISO 糾正措施（CAPA）流程。
階段四・存證歸檔
ReportLab 四方簽署 PDF
自動產出標準化檔名（[員工編號]_[姓名]_[日期].pdf）之官方存證報告，完成歸檔閉環。

⚙️ 技術亮點 (Technical Implementation)

1. 零資料保留架構 (Zero-Data-Retention)

全系統採無狀態記憶體計算，不設後端永久資料庫，用畢即棄，杜絕敏感員工考核個資外洩風險。

2. 確定性透明算法 (ISO 42001)

全面開源 11 項 KPI 數學公式與閥值條件，無黑箱 AI 自動判定，符合高標準演算法可解釋性與稽核要求。

3. 純 Python PDF 引擎 (ReportLab)

捨棄依賴 C 語言底層庫之方案，以純 Python 生成矢量 A4 報表，具備 100% 雲端部署穩定性與跨平台相容度。

4. 行動端觸控極致優化 (Mobile-First)

專為現場大拇指觸控與工地手套操作量身訂製的大尺寸數字增減鍵，免去實體表單攜帶與翻閱負擔。
